# README Generator

Skill para generar READMEs profesionales multilingües para repositorios GitHub.

## Estructura

- Título con badges
- Badges interactivos (visitas, licencia, versión)
- Tabla de contenido
- Descripción del proyecto
- Características (features)
- Instalación
- Uso (con ejemplos de código)
- Tecnologías utilizadas
- Contribuir
- Licencia
- Contacto

## Características

- Soporte multilingüe (ES/EN)
- Badges dinámicos
- Código ejecutable en bloques
- Diseño visual atractivo
- Adaptable al tipo de proyecto (Python, JS, etc.)
