# Guía de Imágenes para README PRO

Este archivo documenta las imágenes necesarias para el README Profesional.

## Imágenes utilizadas

| Imagen | Descripción | Estado |
|--------|-------------|--------|
| `banner.png` | Banner principal del proyecto (1200x630) | ✅ Incluido |
| `screenshot-readme-pro.png` | Captura del README generado | ⚠️ Necesario |

## Cómo generar el banner

El banner se puede generar usando el código en `create_banner.py`:

```bash
cd assets
python create_banner.py
```

O manualmente crear uno con:
- Dimensiones: 1200x630px
- Formato: PNG
- Estilo: Oscuro con acentos violeta y verde

## Capturas de pantalla recomendadas

Para el README se recomiendan:
1. `screenshot-readme-pro.png` - Ejemplo de README generado
2. `screenshot-features.png` - Sección de características
3. `screenshot-contact.png` - Sección de contacto
